# Resume and scope

Read the exact requested artifact and its existing trace once. Restore the
root, completed units, current work and outstanding permissions. Do not
re-run completed units. A terminal trace or shipped marker means done.

Defaults: solo, no commits, no extra reviewers, no full suite. Ask only for
a blocking missing decision. Use absolute target paths, never assume the REPL launch cwd.
For multi-session work, keep one trace.md beside the spec. Inline work needs
no durable files unless requested. A native todo mirrors this progress.

If a command is still running, recover its job instead of starting another.
Inspect native BashHandle/child status for running work and its actual logs
for evidence; the trace stores intent and cross-session acceptance status.
